# Dating Leaderboard

A mobile-first satirical dating ranking app built with React, TypeScript, and Vite. It is configured for Vercel with `vercel.json`.

## Local Verification

Install dependencies:

```bash
npm install
```

Check syntax, TypeScript, and production bundling:

```bash
npm run build
```

Run locally:

```bash
npm run dev
```

Then open the local URL Vite prints, usually `http://127.0.0.1:5173/`.

## First Iteration Scope

- Top-three podium
- Full ranked contender list
- Current-user highlighted row
- Search and tier filtering
- Boost selector sheet with Nudge, Push, and Launch packages
- Simulated boost confirmation state
